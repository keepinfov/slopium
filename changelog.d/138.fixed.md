- `get`, `remove` and `replace` return a `f64` element as the double that was
  stored, on both targets and in both profiles. A builtin hands an element back
  as a machine word, and the word's bits stayed in the integer result register
  where no reader looked, so a float read out of a list arrived as the bits
  reinterpreted: `(get &(list 1.5) 0)` answered `4.7e-324`.

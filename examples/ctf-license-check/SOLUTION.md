# Решение

Обе проверки видны в исходнике:

```text
ticket * 31337 + 7331 = 41904900
pin * 97 - 11 = 411463
```

Отсюда:

```text
ticket = (41904900 - 7331) / 31337 = 1337
pin    = (411463 + 11) / 97       = 4242
```

Отправить значения можно одной командой:

```sh
printf '1337\n4242\n' | nc ctf.example.org 31337
```

На реальном соревновании арифметику можно скрыть сильнее: разбить её между
несколькими функциями, добавить ложные ветви или выдавать только ELF. Этот
вариант намеренно простой и показывает полный путь от Slopium source до
сетевого challenge.

# Checked compact append foundation — 2026-10-28

Issue #159 implements private checked append operations for the owner selected
by `D-167`. The public `Builder` still uses its previous representation;
these diagnostics do not claim that installed programs use compact storage.
Owned production finalization and public integration remain #160.

All append rows improve in both rounds: one-byte pieces by 35.6–48.5%,
five-byte pieces by 75.9–80.8%, and 4096-byte pieces by 80.0–85.6%.
The 50000-record append interval falls 61.8% and 62.7%. These are checked
private-operation measurements, with an unchanged installed public builder.

## What is measured

`append.py` copies the actual `std/core/builder.slp` module without rewriting
its implementation. A temporary diagnostic export list exposes its private
writers, and an adapter uses the existing research `study_finish` function.
The main program calls both public and private writers across the same module
boundary. The append interval includes owner construction, metadata validation,
checked arithmetic, ordinary list growth and all packing calls. Every run
checks logical length and final checksum; all byte, ownership and malformed
state correctness gates are separate deterministic checks.

`research_finalize_ns`, wall time and RSS include that research finalizer.
They are disclosed controls, not production finalization results. It is not
permitted to attribute a research-finalizer result to #160. The original
benchmark source is separately compiled unchanged with the landed baseline
compiler and candidate compiler; neither original executable uses private
packed writers. C/Rust parity is outside this append comparison and remains
part of the final integration report.

The piece matrix covers 1/5/7/8/9/64/4096-byte pieces and 8 KiB, 512 KiB and
4 MiB documents, followed by 50000 records, short integers and 20-digit
integers. Piece counts round down so the logical output fits the requested
document size. Two independently warmed rounds use three warmups and fifteen
shuffled samples per variant, with no startup subtraction. Startup processes
are measured separately. The raw report contains every sample and build
command. There are 1500 checked measured workload invocations, 300 warmups
and 30 startup controls. Local builds and checks finished before sampling;
unrelated host activity was not controlled.

An initial layered implementation regressed one-byte pieces by approximately
20% in exploratory three-sample measurements. The selected implementation
keeps checked scalar metadata live across growth and shares a scalar invariant
validator. The final results below use the actual checked implementation;
the initial smoke measurements are not final evidence.

Research finalization is slower for every 8 KiB case and for short integers.
For example, the 8 KiB one-byte-piece row takes about 6.5 microseconds versus
2.5 microseconds, and short integers take 164/162 microseconds versus
146/131 microseconds. Small whole-process rows vary in both directions;
the 8 KiB nine-byte-piece row is 0.7%/4.5% slower in wall time despite a
75.8%/76.2% faster append interval. These costs remain visible above and in
the raw data. Production finalization and its complete-process comparison
remain required integration work.

The original control cannot demonstrate an installed packed-write gain: its
public writer bodies are unchanged and it never calls the private writers.
Static comparison confirms byte-identical original executables: both are
22536 bytes with SHA-256
`216b04066cfa838f7dc4c5a3131b16e45518b6e62cdc84ca9198c83d6a79a687`.
Main and all seven public builder function bodies also match symbolically.
The raw report's original binary hashes provide a separate identity check.
Original-control timing differences therefore reflect measurement variation,
not different executed programs. Small fresh-process wall intervals
also contain startup, research finalization, checksum and host noise; they do
not substitute for the append intervals.

## Deterministic validation

The full frozen `SLOPIUM_STRICT=1 scripts/verify.sh` passed without skips,
including local-only `nix flake check`. The established private host mount
namespace supplies the fixture shell paths, drops capabilities, and supplies
an identical tracked/new-source snapshot to Nix with binary substitution
disabled. No required stage was omitted. Executable sources and the generated
consumer digest match the gate snapshot and measured source identities.

- Thirteen actual-module tests passed native/AArch64 dev/release, including
  all tail offsets, arbitrary bytes, UTF-8/NUL, repeated mixed growth, integer
  extremes, exact arithmetic preflight and independent clones.
- Each of five invalid owner states was exercised against byte, empty/nonempty
  piece, signed-zero and unsigned-zero writers in all four modes. Ten helper
  failure cases per mode include negative lengths and integer-width/sign
  overflow; all required status 101 and the appropriate diagnostic.
- Native Memcheck and ASan/UBSan passed. A live shared owner loan still receives
  exactly one spanned `SL0300`. Core-only relocatable linkage leaves only the
  four allocator/failure hooks, on both targets/profiles.
- Linker-wrapped calls from the actual Slopium functions assert exactly 131072
  list pushes and 256 packing calls for 1 MiB in 256 nonempty pieces, plus a
  final byte. An empty piece adds no packing call. This is one push per
  completed word, not one capacity decision per piece.
- Direct C checks passed both targets at `-O0`/`-O2`, native Valgrind and
  ASan/UBSan. Each successful matrix covers 80 prefix lengths and fourteen
  piece lengths, checks every output byte, untouched guards and sources, and
  zero tail padding. Ten invalid C cases require the exact panic before pointer
  access. The deliberately unoptimized test row undefines Fortify in the
  preprocessor after Nix wrapper flags; production flags and assertions stay.
- Standard-library fixtures were regenerated serially; only the bundled core
  digest in the consumer lockfile changed. Existing public builder/float
  fixtures passed. No dependency, version or ordinary collection ABI changed.

## Remaining limits

field migration and integration cache/float proof remain #160. Final installed
throughput/RSS and C/Rust comparison remain #161. The research finalizer's
